// usage

One command, any comparison

Run rediff in a repository. It starts a local server, prints its address and opens your browser.

  • rediffWorking tree vs HEAD, untracked files included
  • rediff --cachedStaged changes vs HEAD
  • rediff mainWorking tree vs main
  • rediff main featureTwo branches, side by side
  • rediff HEAD~3..HEAD -- srcA commit range, limited to a path

// features

The pull request review, without the pull request

Everything you rely on when reviewing on GitHub, pointed at the changes on your own machine.

Split or unified

Switch layouts any time. Long lines wrap to fit, and both sides of a split diff stay aligned.

Track what you've read

Mark files Viewed to collapse them, or hide them entirely. A mark clears itself when that file changes again.

Every commit, one click away

History lists the branch's commits; open any one to see its changes. Path arguments filter the list too.

Live as you edit

rediff watches the working tree, index and refs. Save a file and the page catches up in about a third of a second.

Made for remote dev boxes

A network address is printed next to the local one, so a diff on a remote machine opens in your laptop's browser. Every URL carries a one-time token.

Huge diffs stay smooth

Files load as you scroll to them and only visible lines are rendered, so a 200,000-line change scrolls at full frame rate.

Exactly what git says

rediff runs git itself, so .gitattributes, rename detection and your diff.algorithm all match git diff.

Keyboard first

j k between files, / to filter, v to mark viewed, c to collapse, ? for the rest.

// install

Install in one line

  • A single binary with the web UI built in
  • Prebuilt for macOS, Linux and Windows, on x86_64 and ARM64
  • Upgrade any time with rediff-update
$ curl --proto '=https' --tlsv1.2 -LsSf https://github.com/rediff-app/rediff/releases/latest/download/rediff-installer.sh | sh
> powershell -ExecutionPolicy Bypass -c "irm https://github.com/rediff-app/rediff/releases/latest/download/rediff-installer.ps1 | iex"
git clone https://github.com/rediff-app/rediff
cd rediff
make install

Installs to ~/.cargo/bin. Building from source needs Rust, Node.js 20+ and git. Archives for every platform are on GitHub Releases.
